# happyherd-server-self-host

Self-host runtime for [HappyHerd](https://happy.engineering) — the sync server plus
the bundled web app, packaged for `happyherd server`.

## Usage

```bash
npm install -g @happyherd/cli@latest happyherd-server-self-host
happyherd server
```

`happyherd server` (from `@happyherd/cli`) discovers this package automatically and
runs it with embedded PGlite storage and local filesystem uploads — no Postgres,
no Redis, no S3. It writes `settings.serverUrl` so the daemon and CLI target
your local server.

The bundled `happyherd-server` binary can also be run directly:

```bash
happyherd-server migrate   # apply database migrations
happyherd-server serve     # start the server
```

## What this package is

This is the *publishing shell* around `packages/happyherd-server`, which is private
and is what the hosted HappyHerd backend deploys. The server source lives there; this
package bundles its `sources/standalone.ts` entrypoint into `dist/standalone.mjs`
and ships the Prisma schema, migrations, and exported web app alongside it.

Build artifacts (`dist/`, `prisma/`, `webapp/`) are generated by
`scripts/build-runtime.cjs` and `bundle:webapp`; they are not checked in.
